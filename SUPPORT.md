# Support

Thanks for using gloo.foo! Here's where to get help.

## Questions & ideas

- **[GitHub Discussions](https://github.com/gloo-foo/framework/discussions)** — usage questions, ideas, and general help.
- **[Documentation (wiki)](https://github.com/gloo-foo/framework/wiki)** — the pipeline model, building commands, concurrency, and testing.
- **[API reference](https://pkg.go.dev/github.com/gloo-foo/framework)** — godoc for the framework and commands.

## Bugs & feature requests

- **Bugs** — open an issue with the [bug report template](https://github.com/gloo-foo/.github/blob/master/ISSUE_TEMPLATE/bug_report.yml).
- **Features** — open an issue with the [feature request template](https://github.com/gloo-foo/.github/blob/master/ISSUE_TEMPLATE/feature_request.yml).
- **New commands** — use the [command request template](https://github.com/gloo-foo/.github/blob/master/ISSUE_TEMPLATE/command_request.yml).

## Security

Please do **not** report security issues in public. See the [Security Policy](https://github.com/gloo-foo/.github/blob/master/SECURITY.md).
